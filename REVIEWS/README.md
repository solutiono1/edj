# REVIEWS

Planner reviews of frontend-builder patches. One file per TASK.

Format:

```
VERDICT: PASS | CHANGE REQUEST
TASK: TASK-###
SPEC CHECK:
- [x] requirement from SPEC.md / UIUX.md
- [ ] failed requirement
NOTES: specific lines/screens to change
```

A patch is applied by the human only after `VERDICT: PASS`.
